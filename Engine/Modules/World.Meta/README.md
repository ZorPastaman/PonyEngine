# PonyEngine.World.Meta feature module

Provides meta components for worlds.

Adds `PonyEngine.World.Meta` target.

## Dependencies

- [PonyEngine.Core](../Core)
- [PonyEngine.World](../World)

## C\++ modules

### [PonyEngine.World.Meta](Source/Meta.cppm)

#### [Name](Source/Meta-Name.cppm)

Entity name. It's an inline string wrapper.

#### [Description](Source/Meta-Description.cppm)

Entity description. It's an object handle holder. The object must be of type of `std::string_view`.
