# PonyEngine.Core.WinAPI module

Adds WinAPI utilities to [PonyEngine.Core](../Core).

Modifies `PonyEngine.Core` target.

## Dependencies

- [PonyEngine.Core](../Core)
- Windows SDK 10.0.26100.0+

## C\++ modules

### [PonyEngine.FileSystem.WinAPI](Source/FileSystem.cppm)

Utilities for WinAPI file system.

### [PonyEngine.Format.WinAPI](Source/Format.cppm)

Utilities for std::format that add WinAPI types support.

### [PonyEngine.Memory.WinAPI](Source/Memory.cppm)

Memory utilities for WinAPI types.

Utilities:

- [ComPtr](Source/Memory-ComPtr.cppm) - smart pointer for COM objects.

### [PonyEngine.Text.WinAPI](Source/Text.cppm)

Utilities for strings.
