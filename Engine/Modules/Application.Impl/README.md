# PonyEngine.Application.Impl module

Application implementation module.

The module requires a platform specific implementation.

## Dependencies

- [PonyEngine.Application](../Application)
- [PonyEngine.Core](../Core)
- [PonyEngine.Log](../Log)

## CMake variables

These variables are used to configure the build of the module:

| Variable name           | Default value | Description                                                                                                           |
|:------------------------|:-------------:|:----------------------------------------------------------------------------------------------------------------------|
| `PONY_ENGINE_ROOT_PATH` | ""            | Root path. It must be relative to an executable directory, and the folder must exist at runtime. Empty path is valid. |
